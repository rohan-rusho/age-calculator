# Age Calculator 🎂

How old are you, exactly? Your age in years, months and days — plus the countdown to your next birthday.

## Features

- Birthdate picker (future dates rejected)
- Exact age in **years / months / days** — leap years and month lengths handled
- Total days, weeks and months lived
- Next birthday countdown (days until your next birthday, with the weekday it lands on)
- The weekday you were born on
- Your birthdate never leaves your browser — all maths runs locally

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

No build step, no dependencies except Google Fonts. Just open `index.html` or serve the folder.

## Deploy

Any static host works — GitHub Pages, Netlify, Vercel: publish this folder as-is.
